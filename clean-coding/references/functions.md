# Functions (F1–F4) — Examples

### F1: Minimize arguments (0 = ideal, 1 = good, 2 = OK, 3 = warning, 4+ = violation)

```
# Ideal — niladic (0 args)
def get_current_user(): ...

# Good — monadic (1 arg)
def activate_user(user): ...

# Acceptable — dyadic (2 args), but question whether both are needed
def write_field(name, value): ...

# Warning — triadic (3 args), justify or restructure
def make_date(year, month, day): ...   # common enough to accept
def draw_circle(x, y, radius): ...     # consider Point + radius

# Violation — 4+ args, use a data structure
# Bad
def create_user(name, email, age, country, timezone, language, newsletter): ...

# Good
@dataclass
class UserData:
    name: str
    email: str
    age: int
    country: str

def create_user(data: UserData): ...
```

### F2: No output arguments

```
# Bad — mutates argument
def append_footer(report):
    report.append("\n---\nGenerated by System")

# Good — returns new value
def with_footer(report):
    return report + "\n---\nGenerated by System"
```

### F3: No flag arguments

```
# Bad — function does two things
def render(is_test):
    if is_test:
        render_test_page()
    else:
        render_production_page()

# Good — split into two functions
def render_test_page(): ...
def render_production_page(): ...
```

### F4: Delete dead functions

```
# Bad — unused function "just in case"
def legacy_export(data):      # never called anywhere
    return json.dumps(data)

def export(data):
    return csv_format(data)

# Good — delete legacy_export, VCS preserves history
def export(data):
    return csv_format(data)
```
