# Task: Write a Python function

Write a function that calculates the total price for a shopping cart.

Requirements:
- Takes a list of items, each with a price and quantity
- Applies a tax rate (default 19%)
- If the total before tax exceeds 100 EUR, apply a 10% discount before tax
- If express shipping is selected, add a flat shipping fee of 5.99 EUR
- Return the final total rounded to 2 decimal places
